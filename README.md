# Sobesnik

Тренажёр технических собеседований, который работает у тебя на машине.

Вставляешь текст вакансии — Sobesnik вытаскивает из неё стек и уровень, задаёт вопросы
как на настоящем собесе, принимает ответы текстом или голосом и разбирает каждый ответ
по понятным критериям. Слабые темы запоминаются и возвращаются в следующих тренировках.

> Статус: ранняя разработка. Описанное ниже — план, а не готовые функции.

## Зачем ещё один тренажёр

Существующие сервисы подготовки к собеседованиям — платные и облачные: твой голос,
черновые ответы и список пробелов в знаниях уходят чужому серверу.

Sobesnik устроен иначе:

- **бесплатно и с открытым кодом**;
- **разворачивается одной командой** через Docker Compose;
- **может работать полностью локально** — распознавание речи и языковая модель
  запускаются на твоём железе, данные никуда не уходят;
- при желании тот же код поднимается на сервере и подключается к облачной модели.

## Как это будет работать

1. Вакансия → извлечение требований: стек, грейд, ключевые темы.
2. Генерация вопросов под конкретную вакансию и уровень.
3. Ответ текстом или голосом (распознавание речи на базе Whisper).
4. Оценка ответа языковой моделью по рубрике: полнота, точность, глубина, структура.
5. Прогресс: история попыток, слабые темы, повторение.

Интерфейсы: веб-кабинет и Telegram-бот.

## Запуск

Нужны Docker и [Ollama](https://ollama.com). На Mac Ollama ставится на хост: в Docker на Маке нет GPU.

```bash
ollama pull qwen3.5:4b
cp deploy/.env.example .env   # необязательно: без .env работают те же значения
docker compose up -d --build
curl localhost:8000/api/v1/health/llm
```

Пока готовы разбор вакансии и генерация вопросов. Вакансию можно прислать текстом (`text`),
ссылкой (`url`, например на hh.ru) или сохранённой HTML-страницей (`html`).

```bash
USER_ID=$(curl -s -X PUT localhost:8000/api/v1/users/telegram/1 | jq -r .id)
VAC=$(curl -s -X POST localhost:8000/api/v1/vacancies -H 'content-type: application/json' \
  -d "{\"user_id\": \"$USER_ID\", \"url\": \"https://hh.ru/vacancy/137966266\"}" | jq -r .id)
curl -s -X POST localhost:8000/api/v1/sessions -H 'content-type: application/json' \
  -d "{\"vacancy_id\": \"$VAC\", \"n\": 5}" | jq
```

Текст из файла: `jq -n --arg u "$USER_ID" --rawfile t vacancy.txt '{user_id: $u, text: $t}'`
и тот же `POST /vacancies`.

Вместо Ollama можно подключить любой OpenAI-совместимый API: `LLM_PROVIDER=openai_compatible`,
`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` в `.env` (примеры — в `deploy/.env.example`).
Модели для генерации вопросов и для оценки ответов задаются отдельно: `LLM_GEN_*` и `LLM_EVAL_*`.

Документация API — `http://localhost:8000/docs`.

## Структура репозитория

```
apps/api        HTTP API
apps/bot        Telegram-бот
apps/web        веб-кабинет
packages/core   предметная область: вопросы, рубрики, оценки, прогресс
packages/llm    слой провайдеров языковых моделей (локальные и облачные)
packages/asr    распознавание речи
deploy          конфигурации развёртывания
research        эксперименты по качеству оценки
docs            архитектура и решения
```
